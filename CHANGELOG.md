# История изменений

Все заметные изменения этого проекта описаны в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [0.1.0] — 2026-09-16

Первый выпуск: локальное однопользовательское веб-приложение для изучения иностранного языка
в голосовом диалоге с ИИ-тьютором.

### Added

- **Голосовой диалог в обе стороны.** Реплику можно надиктовать и услышать ответ тьютора.
  Распознавание и синтез делает либо браузер (Web Speech API, без установки чего-либо),
  либо серверный OpenAI-совместимый провайдер — режим выбирается переменными
  `STT_PROVIDER` и `TTS_PROVIDER`. Расшифровка попадает в поле ввода и правится учеником
  до отправки, пометка «надиктовано» при этом сохраняется.
- **Определение уровня.** Короткий адаптивный диалог: сложность следующего вопроса считает
  сервер, итог записывает уровень CEFR и уверенность в профиль и открывает первую запись
  истории уровня.
- **Профиль ученика.** Уровень, цели, интересы, дневная норма минут и три отдельных языка —
  изучаемый, интерфейса и объяснений.
- **Учебные материалы.** Загрузка PDF с текстовым слоем, `.txt`, `.md` или вставленного
  текста, разбор на фрагменты, список с фильтрами, просмотр и удаление. Извлечение текста
  синхронное: ответ на загрузку уже содержит финальный статус, а неудача объясняется
  машиночитаемым статусом и текстом для пользователя.
- **План урока.** Генерация плана из 4–7 шагов (разминка, лексика, грамматика, чтение,
  аудирование, говорение, задания, итоги) с целями, минутами и цитатами из выбранных
  материалов; пересборка плана без потери истории урока.
- **Проведение урока.** Комната урока: реплики голосом или текстом, исправления от тьютора,
  переходы по шагам плана, завершение со сводкой. Реплика ученика сохраняется до обращения
  к модели, остальное пишется одной транзакцией после ответа.
- **Задания с проверкой.** Пять видов — перевод, подстановка пропуска, вопрос-ответ,
  множественный выбор и свободная речь; вид задания подбирается под вид шага. Ответ
  проверяет модель, поэтому синонимичная формулировка и речь без пунктуации засчитываются.
- **Прогресс.** Личный словарь со стадиями освоения, журнал ошибок по пяти категориям,
  сводка занятий и история уровня с обоснованием и метриками.
- **Автокоррекция уровня.** Уровень пересчитывается по результатам уроков с защитой от
  дёрганья: минимум завершённых уроков, окно, пороги повышения и понижения, пауза между
  изменениями и не больше одной ступени CEFR за раз.
- **Переключение изучаемого языка.** Английский, русский, немецкий, испанский и французский;
  английский — лишь значение по умолчанию. Интерфейс переведён на русский и английский.
- **Подключение моделей через `.env`.** Языковая модель, распознавание и синтез речи ходят
  по одному OpenAI-совместимому контракту; в `.env.example` три готовых пресета — браузерный
  голос с локальной Ollama, полностью локальный стек в Docker и облачный провайдер.
- **Локальные модели одной командой.** `docker-compose.yml` с независимыми профилями
  `ollama`, `stt` и `tts` плюс `npm run stack:up` / `npm run stack:down`.
- **Дымовая проверка живого стека** `npm run smoke`: здоровье сервера, конфигурация, ответ
  модели, голосовые эндпоинты, профиль, материал, план урока и прогресс — с подсказкой
  «что делать» у каждого провала.
- **Документация:** README, матрица провайдеров `docs/providers.md` и карта кода
  `docs/architecture.md`.

### Security

- Сервер по умолчанию слушает только петлевой интерфейс (`HOST=127.0.0.1`). Аутентификации
  в приложении нет по замыслу, поэтому сетевая привязка — единственная граница доступа
  к профилю, материалам и расшифровкам уроков.
- Список источников CORS задаётся явно (`CORS_ORIGIN`); пустое значение означает «только
  собственный веб на `localhost:WEB_PORT`», а не отражение любого `Origin`.
- Порты контейнеров моделей публикуются только на петлевом интерфейсе: `127.0.0.1:11434`
  (LLM), `127.0.0.1:8000` (распознавание), `127.0.0.1:8880` (синтез).
- Недоверенный текст — цитаты материалов и реплики ученика — уходит в промпты в именованных
  ограничителях и помечен как данные, а не инструкции модели.
- Размеры загрузок ограничены: файл материала, число и размер частей multipart и тело
  JSON-запроса (`MAX_UPLOAD_MB`).
- Сообщение об ошибке конфигурации не печатает значения ключей и вырезает учётные данные
  и строку запроса из адресов провайдеров.

### Known limitations

- Ответы модели не стримятся: на локальной 8B-модели пауза между репликами 5–20 секунд.
- Аудио не сохраняется — в базу попадает только расшифровка, поэтому оценка произношения
  ограничена тем, что модель выводит из текста.
- OCR нет: PDF без текстового слоя принимается со статусом `error_no_text_layer`. Формат
  `.docx` не поддерживается.
- Фрагменты материалов отбираются эвристикой по ключевым словам и бюджету символов, без
  эмбеддингов: на больших PDF релевантность цитат падает.
- Обоснования смены уровня генерируются сервером по-русски и хранятся как есть, поэтому при
  английском интерфейсе останутся русскими.
- Голоса Kokoro не покрывают немецкий и русский — для этих языков серверный синтез не подойдёт.
- Голос «из коробки» требует браузера на Chromium: в Firefox Web Speech API фактически нет,
  там нужен серверный режим распознавания.
- Один пользователь и один профиль; многопользовательского режима и удаления уроков нет.
